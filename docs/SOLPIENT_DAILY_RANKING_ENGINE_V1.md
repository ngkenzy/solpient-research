# Solpient Daily Ranking Engine V1\n\n## Purpose\n\nV1 makes the existing governed Solpient 100 operational every day without weakening historical integrity.\n\nIt separates two cadences:\n\n1. **Governed universe membership cycle** — the broad SEC universe screen and Research Candidate Pipeline decide the immutable Solpient 100 candidate set.\n2. **Daily operational cycle** — update market data for those 100, recompute Phase 3 ranking for published research, and derive Solpient 20 / Solpient 5.\n\nThe current universe methodology activation is bound to an exact validation/input bundle, so V1 does **not** silently rerun a new 4,000+ issuer universe screen every morning.\n\n## Authoritative layers\n\n- **Solpient 100**: latest complete immutable Research Candidate Pipeline shortlist.\n- **Solpient 20**: highest Phase 3 ranked members of the 100 that are `research_ready` or `decision_ready`.\n- **Solpient 5**: highest Phase 3 ranked members of the 100 that are `decision_ready`.\n\nThe engine fails closed: if only three names are Decision Ready, Solpient 5 contains three names. It never pads the list with evidence-incomplete companies just to reach five.\n\n## Local commands\n\nVerify the pure selection rules:\n\n```bash\nnpm run test:lists\n```\n\nPreview the daily orchestration without writing data:\n\n```bash\nnpm run local:daily:dry-run\n```\n\nRun the daily update now:\n\n```bash\nnpm run local:daily\n```\n\nThis executes:\n\n```text\ncurrent immutable Solpient 100\n  -> Yahoo prototype market refresh for only those names\n  -> Phase 3 Decision Ranking refresh\n  -> Solpient 100 / 20 / 5 derivation\n  -> local JSON artifact + automation-run audit record\n```\n\nLatest artifact:\n\n```text\ndata/rankings/solpient-lists-latest.json\n```\n\nChanged inputs also create append-only local artifacts under:\n\n```text\ndata/rankings/history/\n```\n\nThe database remains the authority; the JSON files are operational/read-model artifacts.\n\n## macOS scheduling\n\nInstall a daily 06:30 local-time launchd job:\n\n```bash\nnpm run local:scheduler:install\n```\n\nChoose another time:\n\n```bash\nnode scripts/install-solpient-daily-launchd.mjs --hour=7 --minute=15\n```\n\nRemove it:\n\n```bash\nnpm run local:scheduler:uninstall\n```\n\nLogs:\n\n```text\nlogs/solpient-daily.out.log\nlogs/solpient-daily.err.log\n```\n\n## Integrity rules\n\n- A partial Research Candidate Pipeline run is rejected.\n- The daily job never rewrites a published research version.\n- The 20/5 reuse Phase 3 ranking rather than introducing another stock score.\n- A company outside the governed 100 cannot enter the 20 or 5.\n- Missing readiness does not default to a neutral score.\n- A failed ranking step stops list generation rather than silently publishing a stale new daily result.\n\n## Clean-start / reproducibility check\n\nFrom a fresh checkout with PR #98 local infrastructure available:\n\n```bash\nnpm install\nnpm run test:lists\nnpm run local:daily:dry-run\nnpm run build\n```\n\nWith the restored local PostgreSQL dataset:\n\n```bash\nnpm run local:verify-db\nnpm run local:daily\n```\n\nThe daily run should leave prior immutable database history intact and produce a new ranking snapshot only when Phase 3 state actually changes.\n
